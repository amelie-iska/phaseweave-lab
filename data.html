Read the Parquet fields

FX rows carry split, row_index, triangle, anchor_utc_s, features, margin, persistence, and row_sha256. The features tensor has shape [16, 6, 3] for time, directed edge, and feature channel. Channels contain the centered log rate, scaled quote age, and availability. The cycle margin and persistence arrays each have two entries, one for each direction.

Read the Parquet files with PyArrow or the Hugging Face parquet loader. Join each companion using split, frozen row index, triangle, and anchor. The trade and document companion has a [9, 32] feature array and nine UTC microsecond clocks. An unobserved clock uses -1.

Shared observations and similar inputs

The original 294,912-window audit found no shared quote keys between August training and its evaluation folds. The two October evaluation folds shared 114,450 keys because they reused EUR/JPY and GBP/JPY streams over the same dates.

A new candidate separates early-October development from late-October CHF, keeps each window’s full source support inside its time slice, and screens for near-duplicate rate, age, and availability trajectories using an August-only threshold. The candidate retains 32,873 development and 16,875 CHF windows. It is a retrospective sensitivity analysis.

For FinQA, issuer/report/page groups were disjoint. Training-calibrated question, table, and prose n-grams flagged three out of 48 validation items. The previously scored matched set drops from 42 to 39.
