Paper Desk

Run the local paper desk on Windows, macOS or Linux. It simulates fills against live public quotes and can export the session as JSON. The ZIP includes launchers and requires Python 3.10 or later.

  • Download Desk v8
  • Open the running Paper Desk
  • Setup and controls

Professional Workbench

The same portable desk can read status from local Freqtrade and Hummingbot installations. Use the setup guide to add the optional connectors. Commercial deployment is licensed by agreement.
